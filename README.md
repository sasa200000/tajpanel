# TAJ PANEL 🛡️

پنل مدیریت حرفه‌ای VPN روی **Cloudflare Workers** — بدون VPS، بدون سرور، رایگان و نامحدود.

بر پایه‌ی LML Panel، با تغییرات کامل: برند **TAJPANEL**، تم‌های جدید، لایه‌ی ضد هک دائمی، نمودار زنده‌ی ترافیک و فونت زیبا.

---

## ✨ امکانات

### 🎨 ظاهر
- **۱۳ تم رنگی**: تیره، روشن، صورتی نئونی ☀️ زرد فسفری 🟢 سبز فسفری ⬛ سیاه مطلق 🟫 بژ کلاسیک 💧 آبی، نیمه‌شب، سلطنتی، جنگلی، کریمسون، اقیانوس
- **گالری تم تعاملی** — با یک کلیک تم را عوض کن و زنده ببین
- **فونت Vazirmatn** (فارسی، از CDN)
- حالت تراکم قابل تنظیم (استاندارد/فشرده)
- منوی کناری قابل جمع‌شدن + حالت موبایل
- طراحی RTL کامل

### 📊 نمودار زنده
- نمودار آپلود/دانلود **هر ۲ ثانیه** آپدیت می‌شود (canvas خالص، بدون وابستگی)
- تعداد اتصال‌های آنلاین لحظه‌ای
- آی‌پی‌های فعال و تعداد درخواست‌ها

### 🔒 ضد هک (دائمی)
- **هیچ‌گونه ورود بدون رمز ممکن نیست** (حذف کامل باگ no-password admin)
- **محافظت کامل همه‌ی APIها** — هر مسیر `/api/` غیرعمومی نیاز به session ادمین دارد
- **Rate limiting هوشمند**: ۲۴۰ درخواست در دقیقه برای هر آی‌پی
- **مسیرهای مخرب مسدود**: `.env`, `wp-admin`, `.git`, `xmlrpc.php`, `docker.sock` و ۱۱ مسیر دیگر → آی‌پی متخلف خودکار مسدود می‌شود
- **تشخیص و مسدودسازی تدریجی**: هرچه تلاش بیشتر، محرومیت طولانی‌تر (تا ۲۴ ساعت)
- **Login rate limit**: ۱۵ تلاش در ۱۵ دقیقه
- **Cookie امن**: HttpOnly + Secure + SameSite

### 👥 مدیریت
- کاربران (ایجاد گروهی تا ۵۰ نفر، حجم، مدت، پورت، SNI، ALPN)
- ووچرهای اشتراک (ساخت/لیست/استفاده)
- **نمایندگان فروش (Reseller)** با پورتال اختصاصی
- کانفیگ VLESS / XHTTP روی پورت‌های TLS کلودفلر
- سابسکریپشن خودکار + QR Code
- بکاپ روزانه خودکار به **تلگرام**
- بکاپ/بازیابی JSON
- لاگ‌های ورود ادمین
- ریست خودکار حجم/زمان
- آی‌پی‌پول + تست آی‌پی
- PWA (قابل نصب روی موبایل)

## 🚀 نصب

### ۱) ساخت Worker
1. به [Cloudflare Dashboard](https://dash.cloudflare.com) برو → Workers & Pages → Create Worker
2. نام ورکر را بگذار `tajpanel`
3. کل محتوای [`worker.js`](worker.js) را کپی و Deploy کن

### ۲) ساخت دیتابیس D1
1. Dashboard → Workers & Pages → **D1** → Create database
2. نام: `tajpanel-db`
3. به تنظیمات ورکر برو → **Bindings** → Add binding:
   - Variable name: `DB`
   - D1 database: `tajpanel-db`

> جداول دیتابیس به‌صورت خودکار ساخته می‌شوند — نیازی به دستور SQL نیست.

### ۳) ورود اول
- آدرس ورکر را باز کن (مثلاً `https://tajpanel.<sub>.workers.dev`)
- صفحه‌ی `/login` رمز را می‌خواهد — **اولین رمزی که بزنی، رمز ادمین می‌شود**
- ⚠️ هیچ رمز پیش‌فرضی وجود ندارد — حتماً در اولین ورود یک رمز قوی بزن

### ۴) (اختیاری) دامنه اختصاصی
Workers → Custom Domain → دامنه‌ی خودت را متصل کن. گواهی TLS خودکار فعال می‌شود.

## 📁 صفحات پنل (پیش‌نمایش طراحی)

تمام صفحه‌های پنل به‌صورت HTML مستقل در [`pages/`](pages/) استخراج شده‌اند تا طراحی را ببینی:

| فایل | توضیح |
|---|---|
| [`pages/panel.html`](pages/panel.html) | داشبورد مدیریت اصلی (۱۳ تم + نمودار زنده + گالری تم) |
| [`pages/login.html`](pages/login.html) | صفحه‌ی ورود |
| [`pages/status.html`](pages/status.html) | صفحه‌ی وضعیت اشتراک کاربر |
| [`pages/reseller.html`](pages/reseller.html) | پورتال نمایندگان فروش |
| [`pages/setup.html`](pages/setup.html) | صفحه‌ی تعریف رمز اولیه |
| [`pages/nginx.html`](pages/nginx.html) | صفحه‌ی لندینگ/نود |

> این فایل‌ها فقط برای **دیدن طراحی** هستند؛ ورکر واقعی `worker.js` است که همه‌چیز را سرو می‌کند.

## ⚙️ متغیرهای محیطی (اختیاری)

| متغیر | توضیح |
|---|---|
| `DB` | **الزامی** — binding دیتابیس D1 |
| `CF_API_TOKEN` | برای آپدیت خودکار (غیرفعال پیش‌فرض) |
| `CF_ACCOUNT_ID` | اکانت کلودفلر |
| `WORKER_NAME` | نام ورکر |
