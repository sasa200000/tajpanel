# TAJPANEL 🛡️

پنل مدیریت حرفه‌ای VPN روی **Cloudflare Workers** — بدون VPS، بدون سرور، رایگان و نامحدود.

---

## ✨ امکانات

### 🎨 ۸ تم رنگی
🌸 صورتی · ☀️ زرد · 🟢 سبز فسفری · ⬛ سیاه · 🟫 بژ · 💧 آبی · 🌊 سورمه‌ای · 🔥 نارنجی

گالری تعاملی — با یک کلیک تم عوض می‌شود و زنده می‌بینی.

### 📊 نمودار زنده موج دریا
- آپلود/دانلود هر ۲ ثانیه با خطوط موجی نرم
- نمودار وضعیت کاربران به‌صورت **موج دریا** (نه دایره)
- تعداد اتصال‌های آنلاین لحظه‌ای

### 🔒 ضد هک دائمی
- ورود بدون رمز **غیرممکن**
- همه‌ی APIهای مدیریت محافظت‌شده
- Rate limiting + blocklist خودکار
- مسیرهای مخرب مسدود

### 👥 مدیریت کامل
کاربران (گروهی)، ووچرها، نمایندگان فروش، کانفیگ VLESS/XHTTP، سابسکریپشن + QR، بکاپ روزانه تلگرام، بکاپ/بازیابی JSON، لاگ‌های ورود، ریست خودکار، آی‌پی‌پول + تست آی‌پی، PWA.

### 🔤 فونت
Vazirmatn فارسی از CDN.

## 🚀 نصب

1. [Cloudflare Dashboard](https://dash.cloudflare.com) → Workers & Pages → Create Worker → نام: `tajpanel`
2. کل [`worker.js`](worker.js) را کپی و Deploy کن
3. Workers & Pages → **D1** → بساز دیتابیس `tajpanel-db`
4. تنظیمات ورکر → **Bindings** → `DB` → دیتابیس را انتخاب کن
5. آدرس ورکر را باز کن → **اولین رمزی که بزنی رمز ادمین می‌شود**

> جداول دیتابیس خودکار ساخته می‌شوند.
